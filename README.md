# Mail Template Editor

Модуль редактирования стандартных шаблонов писем для LiveStore / OpenCart 3.x.

**Версия:** 1.4.0  
**Автор:** Dmitry Matveev  
**E-mail:** d.a.matveev@gmail.com

## Возможности

- редактирование `catalog/language/*/mail/*.php`;
- редактирование `catalog/view/theme/*/template/mail/*.twig`;
- автоматическое определение типа отправки по `setHtml()` / `setText()`;
- Summernote по умолчанию для HTML-писем, если другой редактор не активирован;
- безопасный plain-text режим для текстовых писем;
- защита обязательных `printf`- и Twig-плейсхолдеров;
- автоматическая резервная копия перед сохранением;
- поддержка стандартных языков и тем OpenCart/LiveStore;
- встроенная ссылка Donate и QR-код.

## Установка

Готовый пакет находится в:

`dist/mail_template_editor_v1.4.0.ocmod.zip`

Установка через админ-панель:

1. `Дополнения → Установка дополнений`.
2. Загрузить `.ocmod.zip`.
3. `Дополнения → Модификаторы → Обновить`.
4. `Дополнения → Дополнения → Модули`.
5. Установить **Редактор шаблонов писем**.
