Mail Template Editor 1.4.0
Author: Dmitry Matveev
E-mail: d.a.matveev@gmail.com
Donate: https://boosty.to/matveevd/donate

Для LiveStore / OpenCart 3.x.

Возможности:
- редактирование стандартных catalog/language/*/mail/*.php;
- редактирование catalog/view/theme/*/template/mail/*.twig;
- автоматическое определение типа отправки по setHtml()/setText();
- Summernote для HTML-писем, если сторонний редактор не активирован;
- безопасный textarea для plain-text и неопределённых шаблонов;
- защита обязательных printf- и Twig-плейсхолдеров;
- резервная копия исходного файла перед сохранением;
- понятные названия стандартных шаблонов;
- встроенная ссылка Donate на Boosty;
- встроенный QR-код Donate.

Установка:
1. Админка -> Дополнения -> Установка дополнений.
2. Загрузить mail_template_editor_v1.4.0.ocmod.zip.
3. Дополнения -> Модификаторы -> Обновить.
4. Дополнения -> Дополнения -> Модули.
5. Установить «Редактор шаблонов писем».
